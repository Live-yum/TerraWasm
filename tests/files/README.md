# Real compatibility fixtures

This directory contains externally produced binary fixtures used to verify that TerraWasm is compatible with real Terraria files rather than only with files generated by TerraWasm itself.

- `烟花.plr` is a real Terraria player file. PLR compatibility tests must open this file directly, preserve its encrypted bytes on a clean save, edit it semantically, re-encode it, and reopen the result.
- `1.wld` is a real world fixture supplied for WLD compatibility work.

## Fixture rule

Do **not** replace the real `.plr` compatibility fixture with output generated by `terra_plr_open_json`, `terra_plr_encode`, `terra_plr_save_to_buffer`, or another TerraWasm code path. Synthetic fixtures are useful for creation/round-trip unit tests, but they cannot prove compatibility when the encoder and decoder contain the same layout bug.

When adding future PLR fixtures, prefer files created by Terraria itself and keep them stable so CI can detect format regressions.
